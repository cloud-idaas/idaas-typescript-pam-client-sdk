# Changelog

## 0.1.0-beta.2 (Unreleased)

- Publish a maintenance prerelease with no API changes.

## 0.1.0-beta.1

- Support API keys, JWTs, token lifecycle operations, and cloud role credentials.
- Handle unavailable API keys explicitly and improve response validation and error handling.
- Remove deprecated PAM OAuth operations, including `fetchOAuthAuthenticationToken`.
- Provide CommonJS/ESM packages, TypeScript declarations, and English/Chinese usage documentation.
